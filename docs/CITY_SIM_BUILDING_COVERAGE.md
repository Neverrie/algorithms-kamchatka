Все 13 905 записей выбранного тайла Overture происходят из OSM. Это расширение покрытия, а повторяющийся OSM ID означает один и тот же объект. При добавлении сохраняются исходные ID OSM. При конфликте контуров основной снимок имеет приоритет. [Overture STAC, выпуск 2026-11-18.0](https://stac.overturemaps.org/2026-11-18.0/buildings/building/00511/00511.json)

Год постройки и этажность брали из опубликованных муниципальных таблиц. Адрес привязывался при однозначном соответствии улице и номеру или по адресной точке OSM внутри единственного контура. Разные номера корпусов сохраняются. При расхождении публикаций числовое поле в муниципальном наборе остаётся пустым. Карточка объекта ведёт на страницу использованного документа. ## Сверка со снимками и оценка высот

Тайл GlobalBuildingAtlas `asiaeast/e155_n55_e160_n50` содержит в области сцены 4 542 контура, отнесённых авторами набора к собственному слою распознавания, и 11 882 контура OSM. Геометрии совмещены в UTM 57N. Для уверенной связи требовались IoU не ниже 0,50, расстояние между центроидами до 25 м и отсутствие близкого альтернативного совпадения. Совпали 6 независимых контуров с медианным IoU 0,613 и медианным расстоянием 3,57 м. Набор уже объединяет источники, поэтому число совпадений не измеряет точность или полноту всей городской карты. 4 456 полигонов без заметного пересечения с OSM доступны локально в слое «Кандидаты по снимкам». Их геометрия отображается отдельно и не передаётся решателю. [GlobalBuildingAtlas, публикация](https://essd.copernicus.org/articles/17/6647/2025/) · [Лицензия LoD1](https://huggingface.co/datasets/zhu-xlab/GBA.LoD1)

Оценка по этажам использует 3 м на этаж. Для муниципальной этажности показывается также ориентир 2,7–3,3 м на этаж. Модельная высота присутствует у 9 505 сопоставленных объектов. В 129 случаях с числовой высотой OSM медиана абсолютной разницы составила 1,3 м, а в 311 случаях с муниципальной оценкой по этажам — 3,9 м. Это сравнение оценок из разных источников. Геодезическая проверка требует обмеров и независимых координат здания. В контракте решателя поле высоты в метрах заполняется только числовым тегом OSM с признаком `height_verified=false`.

Также проверены индекс Microsoft Global ML Building Footprints и 3D-GloBFP. В индексе Microsoft нет нужного квадрата 131300221. Тайл 3D-GloBFP № 2552 скачан и проверен по MD5. Его 313 полигонов находятся за пределами области сцены. ## Воспроизведение

Муниципальные записи и открытые контуры OSM из Overture входят в репозиторий. Для воспроизведения муниципального файла установите `pdfplumber`, скачайте три PDF в порядке ссылок выше и запустите `python -m city_sim.prepare_buildings --municipal PLAN.pdf UPDATED.pdf GAZETTE.pdf`. Выборка Overture берётся из GeoParquet выпуска по границам сцены. Подайте её в GeoJSON через `--overture`. Для регионального GeoJSON используются поля `id`, `sources`, `height`, `num_floors` и полигон.

Локальный исследовательский кэш с высотами и кандидатами GlobalBuildingAtlas имеет условия CC BY-NC 4.0. Он не входит в Git. Для локальной сборки скачайте `Polygon/asiaeast/e155_n55_e160_n50.geojson`, `LoD1/asiaeast/e155_n55_e160_n50.json` из репозитория GBA.LoD1 и `asiaeast/e155_n55_e160_n50.geojson` из GBA.ODbLPolygon. Выполните `python -m city_sim.prepare_buildings --gba DERIVED.geojson OSM.geojson LOD1.json` и пересоберите Compose. [GBA.LoD1](https://huggingface.co/datasets/zhu-xlab/GBA.LoD1/tree/main) · [GBA.ODbLPolygon](https://huggingface.co/datasets/zhu-xlab/GBA.ODbLPolygon)
